# 🧠 LangChain-Inspired Document Chatbot (Node.js)

> A Node.js-powered AI chatbot that answers user queries from custom documents using OpenAI GPT, vector search (FAISS / Pinecone), and semantic chunking. Built by [Abhijeet](https://abhijeet.live).

---

## 📍 Case Study Overview

I developed an AI chatbot for document-based Q&A, enabling users to upload PDFs or text files and ask questions directly. It uses:

- 🔍 Document parsing + chunking
- 🧠 Vector embeddings (via OpenAI or HuggingFace)
- 📡 Vector DB search (Hsnwlib / Pinecone)
- 🤖 OpenAI GPT for generating responses

This Node.js implementation makes it scalable, production-ready, and easy to integrate into web apps.

---

## 🔧 Tech Stack

- 🟢 Node.js + Express.js
- 📚 PDF parsing (e.g., `pdf-parse`, `pdf2json`)
- 🧠 Embeddings via OpenAI
- 🗂️ FAISS (via Python child process) or Pinecone API
- 🤖 OpenAI GPT-4 for answers

## 🚀 Features

- ✅ PDF/DOCX document ingestion
- 📡 Embedding-based vector similarity search
- 💬 Chat API for user queries
- 🔁 Context-aware Q&A flow
- 🌐 Ready for Angular/React frontend integration
